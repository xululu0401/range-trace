# 越界时段台
纯浏览器工具，2–200条经过分钟/数值记录，按线性插值或左值保持估算低于/范围内/高于时长，超最大间隔整段未知。并排对照两种假设，可保存、JSON备份、CSV全时段、MD全报告、PNG摘要。

运行index.html，无外部依赖。构建node build.cjs；测试node --test tests/core.test.cjs。核心5组包含150随机时序的独立密集中点积分对照，另有解析场景/极限/非法测试。

时间0–10080整数分钟严格递增，数值±10000最多3小数，阈值同单位且下<上。等于界限归范围内，首末记录之间为窗口，末条不额外增加时长。线性按阈值交点切段；保持上一读数采用左闭右开时段。未知不计入覆盖部分范围内占比。零覆盖占比未定义。最长连续越界低/高邻接均连续，遇到范围内或未知中断。

数值乘1000整数比较，交点及时间为浮点。页面保留3位，极短正值<0.0005显示<0.001；CSV保留9位。模型估算不等于连续实测，不考虑传感器误差和漏采尖峰，不用于医疗、食品或法定合格判定。不上传用户读数。

虚构默认窗口60分钟，G15覆盖30未知30；线性低7.5/内15/高7.5、最长7.5；保持10/10/10、最长10。G30保持模式最长连续越界为40分钟（20–30高，30–60低连续）。
